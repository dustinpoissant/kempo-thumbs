Thumbnails

Generated automatically from files in the library, with ffmpeg. Images are decoded, videos give up a frame, and audio files contribute their cover art if they carry one.

What gets a thumbnail

Generate automatically on upload With this off, thumbnails are only made when asked for from this screen.

Sizes

One file is generated per size, per source file. Cover fills the box exactly and crops the overflow; contain fits the whole image inside it and never scales anything up; pad does the same and pads out to the full box.
